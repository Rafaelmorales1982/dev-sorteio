# 🎲 Dev Sorteio

Aplicação web simples para sortear números aleatórios dentro de um intervalo definido pelo usuário.

## 🚀 Funcionalidades

-   Definir valor mínimo e máximo para o sorteio
-   Gerar número aleatório inteiro dentro do intervalo
-   Interface responsiva e com tema escuro

## 🛠️ Tecnologias

-   HTML5
-   CSS3
-   JavaScript (ES6+)

## 📋 Como usar

1.  Abra o arquivo `index.html` no navegador
2.  Preencha os campos **"entre"** (valor mínimo) e **"e"** (valor máximo)
3.  Clique em **"Sortear"**
4.  O número sorteado será exibido na tela
